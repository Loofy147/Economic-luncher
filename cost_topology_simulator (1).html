Build & delivery

Hosting

Vercel

Gateway for every request. Fluid Compute's Active CPU meter excludes I/O wait entirely — a slow AI or DB call doesn't burn CPU billing while it waits.

Watch forProvisioned Memory still bills for the full wait, unlike Active CPU. Streaming responses shortens that memory-duration cost — the AI provider's own token cost is unaffected either way.
Build

Cursor

Pro's $20 bundles a $20 "Other Models" allowance drawn from the same provider APIs priced in the AI Token Lab tab.

Watch forHeavy agentic sessions on a flagship model exhaust the allowance fast. Route boilerplate to a cheap model and save flagship calls for architecture decisions.

Runtime

Database

Supabase

Free to 50,000 MAU; Pro ($25/mo) includes 100,000 MAU plus a $10 compute credit that only covers the Micro instance.

Watch forThe Scale Simulator tab isolates the MAU meter. Compute-tier upgrades, storage, and egress overage are separate lines that grow with real traffic, not account count — budget for them past ~500K MAU.
Cache

Upstash Redis

Free to 500,000 commands/mo. Upgrading to Pay-as-you-go does not carry the free allowance forward — the full volume bills at $0.20/100K.

Watch forSteady traffic above the free tier is usually cheaper on a Fixed plan (from $10/mo) than PAYG. PAYG wins for bursty or idle-heavy workloads only.
Email

Resend

Free to 3,000 emails/mo; Pro ($20–$35) includes up to 100,000; overage is a flat $0.90/1,000.

Watch forScale's lower overage ($0.90 down to $0.46/1,000) looks like a discount, but its higher base fee means Pro + overage stays cheaper in raw price until ~455–460K emails/mo. The toggle above computes the real minimum, not a round-number rule.

AI inference

Provider

Anthropic (Claude)

Flat per-token rate with no long-context surcharge on Sonnet/Opus/Haiku. Cache writes cost 1.25× the base input rate; only reused reads earn the 0.1× discount.

Watch forCaching a turn that's never re-read is a net loss. It pays off only in conversations that revisit the same prefix repeatedly — see the caching toggle in AI Token Lab.
Provider

OpenAI (GPT-5.6)

Sol's promotional $4/$20 rate holds only through Nov 21, 2026, and doubles past a ~272K-token context threshold.

Watch forAn unbounded-history architecture crosses that threshold silently mid-conversation. The AI Token Lab tab marks the exact turn it happens for your B/C settings.
Provider

Google (Gemini)

3.1 Pro doubles input/output past 200K context. The whole 3.x family shares 5,000 free Search-grounding requests/month, then $14/1,000.

Watch forFlash-tier models (3.8 Flash, 3.1 Flash-Lite) don't carry the long-context surcharge — the cheapest place to route high-volume, short-context turns.

Payments

Payments

Stripe

2.9% + $0.30 per transaction — the only line in this whole stack that scales with revenue and order value rather than MAU or token count.

Watch forMany small transactions let the flat $0.30 dominate the effective rate. Model this separately from infrastructure COGS; it doesn't share a growth driver with anything else here.
